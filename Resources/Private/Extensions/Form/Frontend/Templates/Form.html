Fehler auf dem Formular selbst statt auf einem Feld: alles, was ein Validator auf Formularebene ueber addError() meldet (Challenge, MinimumFillTime, EntropySpam im wapplersystems/form-Fork). Kein Feld-Partial zeigt diese an; ohne den Block wird so eine Einsendung stumm abgewiesen. Dieses Template ueberschreibt Form.html fuer jedes Formular der Instanz, deshalb muss der Block hier stehen.

{error -> f:format.htmlspecialchars()}
